# PrintMaster CRM — плагин WordPress

Клиенты, заказы, расчёты (клише, тиснение, печать) и склад материалов для печатной мастерской.
Работает только в админке WordPress (меню **PrintMaster**), на сайте для посетителей ничего не показывает.

## Установка
1. Архив `printmaster-crm.zip` → в админке сайта **Плагины → Добавить новый → Загрузить плагин** → выбрать архив → **Установить** → **Активировать**.
   (Или распаковать папку `printmaster-crm` в `wp-content/plugins/` по FTP/через KAS и активировать в разделе «Плагины».)
2. В меню слева появится **PrintMaster**. Начать с **Настроек** (цены, единицы, коэффициент), затем **Клиенты** и **Материалы**.

Требования: WordPress 6.0+, PHP 7.4+ (на ALL-INKL в KAS → «Tools → Настройки PHP» лучше выбрать 8.2 или новее).

## Доступ и безопасность
- Доступ только у пользователей с правом `pm_manage`; оно выдаётся роли «Администратор» при активации.
- Все формы защищены nonce-проверкой, весь вывод экранируется.
- В данных есть персональные данные клиентов: используйте сложный пароль и двухфакторный вход (любой плагин 2FA), HTTPS на сайте,
  заключите с ALL-INKL договор об обработке данных (AV-Vertrag, есть в KAS) и упомяните учёт клиентов в политике конфиденциальности.
- Если на сайте стоит плагин кеширования, исключите из кеша адреса `/wp-admin/` (обычно уже так по умолчанию).

## Резервные копии
Данные лежат в базе сайта в таблицах `wp_pm_*` (префикс может отличаться) и в настройке `pm_settings`.
Они попадают в обычные резервные копии базы ALL-INKL. При удалении плагина данные не стираются.

## Что и как считается (как в локальной версии)
- Тиснение: (приладка + оттиск × тираж) × 1,05 + фольга (тираж × площадь × 1,05 × цена), всё × коэффициент; площадь оттиска не меньше 50 см².
- Печать: цена листа × цветность (4+4 = ×2) × тираж × плотность бумаги (90 г ×1, 150 г ×1,2, 200 г ×1,4, 300 г ×1,6). Без коэффициента.
- Клише: площадь с технологическими полями × цена за единицу площади, не меньше минимальной цены, × количество. Без коэффициента.
- Склад: материал резервируется при оформлении заказа; списывается со склада, когда заказ получает статус «Выполнен»; возврат из «Выполнен» снова ставит его в резерв;
  удаление заказа снимает резерв или возвращает списанное.

## Проверка логики
`WP_LOAD=/путь/к/wp-load.php php tests/run.php` — только на тестовой установке (скрипт очищает таблицы плагина!). В архив для сайта эта папка не входит.
