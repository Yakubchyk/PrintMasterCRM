# PrintMasterCRM (локальная версия)

Программа для одного компьютера: клиенты, расчёты тиснения, печати и клише, заказы, учёт материалов.
Входа по паролю нет, программа слушает только `127.0.0.1` (доступна только с этого компьютера).

## Запуск (без IntelliJ)
Адрес программы: http://localhost:8765 (порт 8765, чтобы не пересекаться с другими проектами на 8080).

**Вариант 1 — приложение (рекомендуется).** Один раз двойной щелчок по `build-app.command`: появится `dist/PrintMaster CRM.app`
со встроенной Java. Перетащите его в «Программы» и запускайте как обычную программу — браузер откроется сам.
Повторный запуск при уже работающей программе просто открывает вкладку. Значка в Dock у приложения нет (иначе он постоянно прыгает) — добавьте http://localhost:8765 в закладки браузера. Остановка: кнопка «Выход» в меню программы.
После каждого обновления программы `build-app.command` нужно выполнить заново (данные при этом сохраняются).

**Вариант 2 — скрипт.** Двойной щелчок по `start.command`: соберёт программу (если были изменения), запустит и откроет браузер. Нужна Java 17+.

**Windows.** `.app` работает только на Mac. На Windows нужна JDK 17+, затем: `start.bat` (сборка и запуск) или `build-app.bat`
(собирает `dist\PrintMaster CRM\PrintMaster CRM.exe` со встроенной Java; собирать надо на самом Windows-компьютере).
Данные там лежат в `%USERPROFILE%\PrintMasterCRM-data`. Перенести данные между компьютерами — скопировать эту папку.

**Из IntelliJ** — как раньше, запуск `PrintMasterCrmApplication` (браузер сам не открывается).

Журнал работы: `~/PrintMasterCRM-data/printmaster.log` — смотреть, если программа не открылась.

## Где данные
Файл базы: `~/PrintMasterCRM-data/printmaster.mv.db`. Для резервной копии остановите программу и скопируйте этот файл.
Другую папку можно задать переменной окружения `PRINTMASTER_DATA`.

## Настройки
Раздел «Настройки»: цены, единицы измерения (мм/см, см²/м²) и коэффициент (по умолчанию 1.25, применяется только к тиснению).

## Если нужен доступ с другого компьютера
В `application.yml` уберите `server.address`. Без входа по паролю делать это можно только в доверенной сети.

## Как устроены разделы

- **Клиенты** — только данные клиента (название, телефон, email, адрес: индекс, город, улица, дом) и краткий список его заказов.
- **Заказы** — список клиентов со сводкой; клик по клиенту открывает его заказы с подробностями. Строка поиска ищет по клиенту, номеру заказа, описанию и названиям материалов.
- **Новый заказ** — сначала выбираются работы (клише / тиснение / печать), затем показываются только нужные расчёты, после этого заказ оформляется.
- **Клише** — в расчёте указываются рабочий размер, технологические поля (с каждой стороны) и материал (магний/латунь). Цена считается по общему размеру, он виден в заказе.

## Склад (материалы)

Раздел «Материалы» — небольшой склад с тремя разделами:

- **Фольга для тиснения** — тип (золото, серебро, матовое золото, матовое серебро, цветная), ширина рулона, намотка в метрах и число рулонов; остаток считается в см² (ширина × намотка × рулоны). В расчёте тиснения выбирается фольга: резервируется размер оттиска × тираж.
- **Бумага и картон** — учёт в листах (только целые числа), у материала есть поле «Размер листа»;
- **Клише → Магний** и **Клише → Латунь** — учёт в см².

Магний и латунь заносятся по исходному листу: указываются ширина и длина листа и число листов,
остаток считается в см² (ширина × длина × листы). Новые листы принимаются на странице материала («Приход листами»).
Заказы на клише списывают площадь с этого остатка.

Материалы заносятся приходом (на странице материала или начальным остатком при создании).
При оформлении заказа материал **резервируется** (клише — автоматически: общая площадь с полями × количество;
бумага — количеством листов, которое вы указали). Резерв уменьшает «свободно», но остаток на складе не меняется.
Когда заказ получает статус «Выполнен», материал **списывается** со склада; при возврате из «Выполнен» — возвращается в резерв.
Если свободного материала не хватает, заказ не создаётся. Удаление заказа снимает резерв (или возвращает уже списанное).
Материал можно удалить кнопкой «Удалить», если он не использовался в заказах.
