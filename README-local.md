# PrintMasterCRM (локальная версия)

Программа для одного компьютера: клиенты, расчёты тиснения, печати и клише, заказы, учёт материалов.
Входа по паролю нет, программа слушает только `127.0.0.1` (доступна только с этого компьютера).

## Запуск
- Двойной щелчок по `start.command` (первый запуск собирает программу, нужна Java 17) и браузер откроет http://localhost:8080
- или из IntelliJ: запустить `PrintMasterCrmApplication`

## Где данные
Файл базы: `~/PrintMasterCRM-data/printmaster.mv.db`. Для резервной копии остановите программу и скопируйте этот файл.
Другую папку можно задать переменной окружения `PRINTMASTER_DATA`.

## Настройки
Раздел «Настройки»: цены, единицы измерения (мм/см, см²/м²) и коэффициент (по умолчанию 1.25 ко всем расчётам).

## Если нужен доступ с другого компьютера
В `application.yml` уберите `server.address`. Без входа по паролю делать это можно только в доверенной сети.
